# Chapter 3 supplementary videos

This folder contains supplementary videos associated with Chapter 3 of the thesis. The videos illustrate different aspects of the cell migration model, including active force generation, adhesion dynamics, the temporal coordination between polymerisation and contraction forces, and the influence of ECM mechanics and anisotropy on migration.

## Videos

* [Video S3.1](Video_S3_1_Cell_on_rigid_substrate_Logistic_profile.mp4): **Cell migration on a rigid substrate.**
  Simulation of cell migration on a rigid substrate using logistic-type polymerisation and contraction force profiles.

* [Video S3.2](Video_S3_2_Cell_on_fibres_Jump_profile.mp4): **Cell migration on an elastic fibrous ECM with jump-type force profiles.**
  Simulation of the cell migration model coupled to a deformable fibrous ECM using jump-type polymerisation and contraction force profiles.

* [Video S3.3](Video_S3_3_Cell_on_fibres_Triangular_profile.mp4): **Cell dynamics on an elastic fibrous ECM with triangular force profiles.**
  Simulation of the cell migration model coupled to a deformable fibrous ECM using triangular polymerisation and contraction force profiles.

* [Video S3.4](Video_S3_4_Cell_on_fibres_Logistic_profile.mp4): **Cell migration on an elastic fibrous ECM with logistic-type force profiles.**
  Simulation of the cell migration model coupled to a deformable fibrous ECM using logistic-type polymerisation and contraction force profiles.

* [Video S3.5](Video_S3_5_Cell_on_viscoelastic_substrate.mp4): **Cell migration on an isotropic viscoelastic continuum substrate.**
  Simulation of the cell migration model coupled to an isotropic viscoelastic continuum representation of the ECM using logistic-type force profiles.

* [Video S3.6](Video_S3_6_Cell_on_horizontally_pre-stretched_fibrous_substrate.mp4): **Cell migration on a horizontally pre-stretched fibrous ECM.**
  Simulation illustrating cell migration on a fibrous ECM subjected to horizontal pre-stretching. The polymerisation and contraction forces follow logistic-type profiles.

* [Video S3.7](Video_S3_7_Cell_on_vertically_pre-stretched_fibrous_substrate.mp4): **Cell migration on a vertically pre-stretched fibrous ECM.**
  Simulation illustrating cell migration on a fibrous ECM subjected to vertical pre-stretching. The polymerisation and contraction forces follow logistic-type profiles.
